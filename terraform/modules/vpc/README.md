# VPC Module

## Purpose

This module provisions the networking foundation for the NovaSupply Platform.

## Features

- VPC
- Public Subnets
- Private Subnets
- Database Subnets
- Internet Gateway
- NAT Gateway
- Route Tables
- VPC Flow Logs

## Availability Zones

- ap-south-1a
- ap-south-1b
- ap-south-1c

## CIDR

10.0.0.0/16

## Outputs

- VPC ID
- Public Subnet IDs
- Private Subnet IDs
- Database Subnet IDs
